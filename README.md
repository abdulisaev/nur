# Нур — Азкары и Коран

Минималистичное веб-приложение в стеклянном стиле Apple, которое работает и в браузере (PWA), и как **Mini App в Telegram**.

## Что внутри

**Время намаза** (главный экран) — следующий намаз с обратным отсчётом, расписание на любой день, тахаджуд.
- Астрономический расчёт прямо на устройстве — работает офлайн, летнее время учитывается автоматически.
- Источники расчёта: Муфтият РД (параметры подобраны по официальному расписанию Махачкалы — совпадение до минуты), ДУМ России, Всемирная исламская лига, Умм аль-Кура, Диянет, Египет, Карачи, ISNA.
- Расчёт Асра: стандартный (шафиитский, маликитский, ханбалитский) или ханафитский.
- Ручные поправки ±60 минут для каждого намаза; 37 городов (Дагестан, Кавказ, Россия, СНГ, Мекка, Медина) или геолокация.
- Утренние и вечерние азкары предлагаются по фактическому времени намаза.

**Азкары** — 116 зикров в 8 разделах: утренние, вечерние, после намаза, перед сном, при пробуждении, на каждый день, зикры и истигфар, дуа из Корана.
- Арабский текст с огласовками, русская транскрипция и перевод.
- У каждого зикра указаны источник (аль-Бухари, Муслим и др.) и степень достоверности, у многих — достоинство.
- Только «сахих» и «хасан»; тексты сверены с «Крепостью мусульманина», коранические — с текстом Tanzil.
- Счётчик на каждой карточке, общий прогресс раздела, автопереход к следующему зикру, ежедневный сброс, вид «списком» или «карточками».

**Коран** — 114 сур, Усманский текст (Tanzil) и переводы смыслов: Кулиев, Абу Адель, Османов.
- Поиск по названию, номеру или ссылке `2:255`; джузы, закладки, «продолжить чтение».
- 20 чтецов: аль-Афаси, Абдуль-Басит (муратталь и мужаввад), ас-Судайс, аль-Муайкли, аш-Шурайм, ад-Даусари, аль-Гамиди, аль-Хусари, аль-Миншави, аш-Шатыри, аль-Аджми, ар-Рифаи, аль-Катами, Фарис Аббад, аль-Хузайфи, аль-Джухани, Мухаммад Айюб, Мухаммад Джибриль, Абдуллах Басфар.
- Аудио по аятам: подсветка и автопрокрутка, повтор аята (1–10, ∞), скорость 0.75–2×, переход к следующей суре, управление с экрана блокировки.
- Режимы «аяты с переводом» и «мусхаф» по страницам (604 страницы Мединского издания, листание свайпом).

**Тасбих** — пресеты, последовательности «после намаза» (33·33·33·1) и «перед сном» (33·33·34), свой зикр, любая цель, круги, статистика за день и за всё время.

**Настройки** — 9 тем (Системная, Светлая, Тёмная, Изумруд, Пустыня, Полночь, Роза, Чёрная, Telegram), акцентный цвет, сила эффекта стекла, живой фон; 5 арабских шрифтов и 5 шрифтов перевода, размеры, межстрочный интервал, выравнивание; вибрация, звук, поведение счётчика.

**Офлайн** — интерфейс, азкары и тасбих работают без интернета после первого запуска; Коран (~3 МБ) скачивается целиком в разделе «Офлайн-режим». Аудио — только онлайн.

## Запуск на компьютере

```bash
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```

Откройте http://localhost:5173. На localhost Service Worker отключён, чтобы правки были видны сразу; для проверки офлайна откройте http://localhost:5173/?sw

## Публикация

Mini App должен открываться по **HTTPS**. Сервер не нужен — это статический сайт.

- **Netlify Drop** (проще всего): зайдите на app.netlify.com/drop и перетащите папку проекта.
- **GitHub Pages**: загрузите файлы в репозиторий → Settings → Pages → Deploy from branch → `main` / root. Адрес будет вида `https://<логин>.github.io/<репозиторий>/`.
- Подойдут также Cloudflare Pages и Vercel.

Все пути относительные, поэтому приложение работает и в подпапке.

## Подключение к Telegram

1. В [@BotFather](https://t.me/BotFather): `/newbot` → имя и username бота. Токен никому не передавайте (для Mini App он не нужен).
2. Кнопка меню: `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → вставьте HTTPS-адрес сайта и подпись, например «Открыть».
3. Прямая ссылка (по желанию): `/newapp` → выберите бота → название, описание, картинка 640×360 (`icons/telegram-cover-640x360.png`), адрес сайта и короткое имя. Ссылка будет `https://t.me/<бот>/<короткое_имя>`.
4. Чтобы в профиле бота была кнопка «Открыть»: **Bot Settings** → **Configure Mini App** → **Enable Mini App**.

### Диплинки

Добавьте к ссылке параметр `startapp`:

| Ссылка | Что откроется |
| --- | --- |
| `?startapp=quran_18` | Сура аль-Кахф |
| `?startapp=quran_2_255` | Аят аль-Курси |
| `?startapp=azkar_morning` | Утренние азкары (`evening`, `prayer`, `sleep`, `waking`, `daily`, `dhikr`, `quran-duas`) |
| `?startapp=tasbih` | Тасбих |

### Что использует Telegram API

Нативная кнопка «Назад», вибрация (HapticFeedback), цвет шапки под тему, отключение закрытия свайпом при чтении и счёте, полноэкранный режим, «Добавить на главный экран», синхронизация настроек и закладок между устройствами через CloudStorage, тема «Telegram» из цветов клиента.

> Офлайн-запуск внутри Telegram работает на Android и десктопе. Telegram на iOS не поддерживает Service Worker, поэтому там приложение открывается при наличии интернета, но уже открытые и скачанные суры читаются и без сети.

## Обновление версии

После изменений поменяйте `VERSION` в `sw.js` — у пользователей обновится кэш интерфейса.

## Структура

```
index.html, manifest.webmanifest, sw.js
css/app.css                 — стиль, темы, стекло
js/app.js                   — точка входа
js/core/                    — навигация, Telegram, настройки, тема, шрифты, данные, аудио,
                              время намаза, PWA (офлайн, установка), звук
js/views/                   — главная, азкары, Коран, мусхаф, тасбих, время намаза, настройки, плеер
js/data/azkar.js            — азкары (текст, транскрипция, перевод, источники)
js/data/surahs.js           — названия сур, джузы
js/data/quran-meta.js       — арабские названия сур, число аятов, место ниспослания
js/data/reciters.js         — чтецы
data/quran/<издание>/NNN.json — текст и переводы по сурам
icons/                      — иконки приложения и обложка для BotFather
tools/serve.ps1             — локальный сервер для проверки (http://localhost:5173)
tools/build-quran.ps1       — заново скачать текст Корана и переводы
tools/make-icons.ps1        — перерисовать иконки и обложку для BotFather
```

## Источники и лицензии

- Текст Корана — [Tanzil Project](https://tanzil.net), распространяется без изменений с указанием источника.
- Переводы смыслов (Кулиев, Абу Адель, Османов) — через Tanzil / alquran.cloud, только для некоммерческого использования; для коммерческого нужно разрешение правообладателей.
- Аудио — everyayah.com.
- Азкары — «Крепость мусульманина» (Са'ид аль-Кахтани) и первоисточники хадисов; переводы и транскрипция составлены для этого приложения.
- Шрифты — Google Fonts (OFL).
